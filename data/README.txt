Dataset setup
=============
This ZIP intentionally does not include the dataset.

1. Download the Fake and Real News Dataset:
   https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset

2. Extract the archive.
3. Copy Fake.csv and True.csv into this data/ directory.
4. From the project root, run:
   python train_model.py

Check the dataset license before redistribution or commercial use.
